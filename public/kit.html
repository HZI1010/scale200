Security Checklist

1 of 6
  • API keys and database URLs stored in environment variables, never in code.
  • Authentication added to every route that handles user data.
  • Rate limiting on public endpoints to prevent abuse and runaway API costs.
  • CORS locked down to your actual domain, not *.
